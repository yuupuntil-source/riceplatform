RiceDB API Documentation

Database()

Overview

The Database class is the entry point of every RiceDB application.

It manages the connection between your Python program and the SQLite
database. Every database operation begins by creating a Database object.

If the specified database file does not exist, RiceDB automatically
creates it. No additional setup or database server is required.

A single Database object can be be used to create tables, insert
records, update existing data, delete records, execute SQL statements,
and manage the entire database.

Parameters

database

Type

String

Description

The filename or path of the SQLite database.

Example

students.db

Returns

Returns a Database object.

The returned object provides access to every RiceDB API.

Example

from ricedb import Database

db = Database(“students.db”)

Notes

RiceDB automatically creates the database file if it does not exist.

SQLite is included with Python, so no additional software installation
is required.

One Database object is sufficient for most applications.

create_table()

Overview

Creates a new table inside the current database.

A table contains one or more columns. Each column is defined using a
Python dictionary. The dictionary key represents the column name, while
the dictionary value represents the RiceDB data type.

If a table with the same name already exists, RiceDB raises an exception
instead of replacing the existing table.

Parameters

table_name

Type

String

Description

The name of the table to create.

columns

Type

Dictionary

Description

A collection of column definitions.

Each key is a column name.

Each value is a RiceDB data type.

Example

db.create_table(

“students”,

{

“id”:“id”,

“name”:“str”,

“age”:“int”,

“score”:“float”,

“created”:“timenow”

}

)

Description

The example above creates a table named students.

The id column becomes an auto-increment primary key.

The name column stores text values.

The age column stores integer values.

The score column stores floating-point numbers.

The created column automatically stores the current date and time
whenever a new record is inserted.

insert()

Overview

Adds a new record to an existing table.

Only the columns provided in the dictionary will be inserted. Any
remaining columns will use their default values or NULL.

RiceDB automatically uses parameterized SQL statements to improve
security and reduce the risk of SQL injection attacks.
